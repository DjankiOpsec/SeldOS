# Host-Side Audio Preview & Testing Tools 🛠️

> **ВНИМАНИЕ:** Данная директория содержит вспомогательные скрипты исключительно для **предварительного тестирования звука и темпа под хост-системой (Linux)** без необходимости постоянного запуска QEMU.
>
> **Каноническая реализация Оракула для SeldOS / SNL** находится в:
> `userspace/bin/oracle/` (C99, Ring 3, libsnl, SeldFS).

---

## Использование для тестирования звучания:

1. **Прослушать обновленную музыку и ритм прямо сейчас (через aplay):**
   ```bash
   python3 tools/host_test/preview.py
   ```
   *(Воспроизведет фрагмент священного канона в исправленном гармоническом ладу с ровным темпом)*

2. **Задать конкретное количество слов:**
   ```bash
   python3 tools/host_test/preview.py 20
   ```

3. **Слушать минуту музыки (по умолчанию):**
   ```bash
   python3 tools/host_test/preview.py 144
   ```
